# Atividade de Programação Orientada a Objetos em Java

## Sobre o projeto

Este repositório contém a resolução de uma lista de exercícios da disciplina de Programação Orientada a Objetos (POO), desenvolvidos utilizando a linguagem Java.

O objetivo é praticar e aplicar os principais conceitos da programação orientada a objetos por meio de exemplos práticos.

## Tecnologias utilizadas

- Java
- Visual Studio Code
- Git e GitHub

## Conceitos praticados

- Classes e objetos
- Encapsulamento
- Construtores e métodos
- Herança
- Sobrescrita de métodos
- Polimorfismo
- Classes abstratas
- Interfaces
- Coleções
- Tratamento de exceções

## Como executar

1. Clone este repositório.
2. Abra o projeto no Visual Studio Code.
3. Acesse a pasta do exercício desejado dentro de `src`.
4. Execute o arquivo `Main.java` correspondente.
